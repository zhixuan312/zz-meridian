# Evidence for 0.5.0

What the 0.5.0 release claims, the command that shows it, and the decisive output of the run that did. Every run named
"local" was made on the maintainer's MacBook (an Apple M5): a comparison, not reference-profile evidence. The three
timed runs of the default verify on GitHub's ubuntu-24.04 4-CPU runner (each at most 120 s) belong to the release
workflow and are **not run yet**; their rows say so and carry no number. Commits are on `master`; the decisions the
numbers rest on are in `decisions/0010-the-adopter-contract.md`.

Commands run from the repository root unless a row says otherwise. The consumer smoke packs the CLI first:

```sh
node cli/scripts/build-payload.ts && (cd cli && npm pack)
```
